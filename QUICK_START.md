# 🚀 Quick Start Guide - Automotive QE Local Web App

## Welcome!

Your Automotive QE application is now a **fully functional local web app** with **persistent data storage**. This guide will get you up and running in 2 minutes.

## ⚡ Quick Start (2 Minutes)

### Step 1: Open the App
- Open `dist/index.html` in your browser
- Or serve with: `npm run dev`
- Sample data loads automatically

### Step 2: Explore
- Navigate using the sidebar
- Check out Dashboard, Projects, CMM Reports
- See the green "Saved" indicator in sidebar

### Step 3: Make Changes
- Add a project
- Import some data
- Watch the save indicator update

### Step 4: Verify Persistence
- Close the browser
- Reopen the app
- Your data is still there! ✓

### Step 5: Create Backup
- Go to **Settings** (gear icon)
- Click **"Export All Data"**
- Save the JSON file safely

**Done!** You're ready to use the app. 🎉

## 🔄 Common Tasks

### Task 1: Create First Backup
1. Click **Settings** in sidebar
2. Click **"Export All Data"**
3. Save the JSON file
4. Name it: `backup-YYYY-MM-DD.json`
5. Store in safe location

### Task 2: Add New Project
1. Click **Projects** in sidebar
2. Click **"New Project"**
3. Fill in details
4. Click **Save**
5. Check sidebar - see "Saved" indicator ✓

### Task 3: Import CMM Report
1. Click **CMM Reports** in sidebar
2. Click **"Import Reports"**
3. Select your file
4. Data loads and saves automatically ✓

### Task 4: Restore from Backup
1. Go to **Settings**
2. Click **"Import Data from File"**
3. Select your backup JSON
4. Page reloads with restored data ✓

## ⚠️ Important Warnings

### ❌ Don't Forget to Export!
- Browser data can be cleared
- Always export before clearing browser data
- Keep multiple backup copies

### ❌ Don't Edit JSON Manually
- Use the app UI for changes
- Manual edits can corrupt data
- Export → Edit in app → Export again

### ❌ Don't Assume Sync
- Each browser has separate data
- Each device has separate data
- Export/Import to transfer

---

## 🆘 Troubleshooting

### Problem: Data disappeared
**Solution**: Import from your last backup

### Problem: Can't save
**Solution**: Check if localStorage is enabled

### Problem: Export doesn't work
**Solution**: Check pop-up blocker settings

### Problem: Import fails
**Solution**: Verify file is valid JSON backup
